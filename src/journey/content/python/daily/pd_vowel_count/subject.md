# Count the vowels

Daily · uses levels 1 to 4

## Assignment

Read one line of text and print how many vowels (`a e i o u`, in either case) it
contains.

    $ python3 vowel_count.py
    hello
    2

## Things to think about

You can loop straight over a string: `for ch in text:` gives you one character
at a time. A counter that you start at 0 and increase with `count += 1` keeps the
total.
