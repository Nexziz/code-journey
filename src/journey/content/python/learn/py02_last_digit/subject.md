# The last digit

Level 2 · new skill: **variables**

## Assignment

Read a non-negative whole number and print its last digit.

    $ python3 last_digit.py
    61
    1

## What you need to know

`input()` gives a string. To do arithmetic you need a number: `int("61")` is the
number 61, so `number = int(input())` reads a number in one line.

`%` is the remainder of a division: `61 % 10` is `1`. The other operators are
`+ - *`, `/` (a decimal result, like `7 / 2` is `3.5`), `//` (whole-number
division, `7 // 2` is `3`) and `**` (a power).
