# Ready, set, go

Level 1 · new skill: **output**

## Assignment

Print three lines:

    Ready
    Set
    Go!

## What you need to know

Every `print` call ends its line. Three lines means three calls.
A `\n` inside a piece of text is a newline, so one call could also print several
lines, but three clear calls read better.
