# Hello, terminal

Level 1 · new skill: **output**

## Assignment

Write a program that prints exactly this line:

    Hello, World!

## What you need to know

A Python program is a text file that runs from its first line to its last.
`print` sends text to the terminal and adds a newline at the end for you:

    print("some text")

Text goes between quotes. Single quotes work too: `'some text'`.

## Run it

    python3 hello.py
