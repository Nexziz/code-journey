# The larger one

Level 5 · new skill: **functions**

## Assignment

Write a function that returns the larger of two integers:

    int ft_max(int a, int b);

## What you need to know

A function can give a value back with `return`. The test program prints the
value it gets: your function must **not print anything**, only return.

This exercise needs no outside functions at all, so there is no `write` and no
`#include`. Do not subtract the two numbers to compare them: that overflows for
the extreme values.

## Turn in

- Files: `ft_max.c`
- Allowed functions: none
