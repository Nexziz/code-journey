# Negative or not

Level 5 · new skill: **functions**

## Assignment

Write a function that tells you whether a number is negative:

    void ft_is_negative(int n);

It prints `N` if `n` is negative and `P` if `n` is positive or zero. No
newline: the test program prints its own.

## What you need to know

The parameter `n` is a copy of whatever the caller passed in, so you can read it
and compare it like any variable. Nothing else is new: this is a condition
(level 4) packaged in a function (level 5).

## Turn in

- Files: `ft_is_negative.c`
- Allowed functions: `write`
