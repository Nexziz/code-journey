# Negative or not

## Assignment

Write a function that tells you whether a number is negative:

    void ft_is_negative(int n);

It prints `N` if `n` is negative and `P` if `n` is positive or zero. No
newline: the test program prints its own.

## Turn in

- Files: `ft_is_negative.c`
- Allowed functions: `write`
- No `main`: a test program calls your function.
